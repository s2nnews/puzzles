# research/ — local-only working notes

Scratch space for market and supply-side research: brand prospecting,
competitor teardowns, category scans, and the decision records that go with
them.

**Everything in this folder is gitignored except this README.** That is
deliberate. These notes name suppliers and prospective suppliers, and this
repo is public — see the rule in `CLAUDE.md`. Nothing here should ever reach
`data/processed/index.json`, the charts, or site copy, and no source platform
or supplier should be named in any published output.

Conventions:

- One Markdown file per piece of research, named `YYYY-MM-DD-topic.md`.
- Open with a **Status** line — `ACTIVE`, `PARKED`, or `SUPERSEDED` — so a
  future read knows whether it is a live workstream or a closed question.
- When research leads to a decision *not* to act, record the reasoning and the
  conditions that would justify revisiting. That is the durable part; the
  underlying facts go stale within months and the reasoning does not.
- These files live only on the local machine. Back them up outside the repo —
  a clean checkout will not have them.
